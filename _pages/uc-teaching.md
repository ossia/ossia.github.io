ossia score is used in classes and workshops to teach interactive sound, video, lighting and installation, for instance at Concordia University, UQAM, the University of Ottawa, Queen's University (Kingston, Ontario), Maynooth University and the Université de Bordeaux.
Students keep the same tool after the course: it is free, it runs on their own computer, and projects open on every operating system.

## What you can do

- **Nothing to install**: the [browser version](https://ossia.io/score-web) runs with the camera, the microphone, MIDI controllers, gamepads and OSC, and opens the examples and zipped projects directly.
- **The same tool everywhere**: Windows (x64 and ARM), macOS, Linux and Raspberry Pi, with the same project files and the same features, except for features tied to an operating system or to hardware, such as Spout, Syphon or CUDA ([embedded](https://ossia.io/score-docs/in-depth/embedded.html)).
- **Learn by example**: a library of example scores for audio, video, 3D, AI, devices and data, and links from each object to its documentation ([examples](https://ossia.io/score-docs/examples.html), [quick start](https://ossia.io/score-docs/quick-start.html)).
- **From patching to code**: start with cables and timelines, then write JavaScript, Faust, shaders or C++ in the same project ([JavaScript](https://ossia.io/score-docs/processes/javascript.html), [shaders](https://ossia.io/score-docs/processes/shaders.html), [Faust](https://ossia.io/score-docs/processes/faust.html)).
- **Every discipline in one place**: sound and synthesis, video and 3D, DMX lighting, sensors and Arduino, computer vision and AI, so a class project can combine them.
- **Accessible**: about thirty skins, including colour-blind-safe and high-contrast ones.
- **Cheap hardware for kits**: a Raspberry Pi runs a finished project without a screen, with GPIO for electronics ([headless mode](https://ossia.io/score-docs/faq/nogui.html)).
