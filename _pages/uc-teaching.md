ossia score is used in classes and workshops on interactive sound, video, lighting and installation, for instance at Concordia University, UQAM, the University of Ottawa, Queen's University (Kingston, Ontario), Maynooth University and the Université de Bordeaux.
Students keep using it after the course: it costs nothing, it runs on their own computer, and their projects open on any operating system.

## The first session

The [browser version](https://ossia.io/score-web) needs no installation. It uses the camera, the microphone, MIDI controllers, gamepads and OSC, and opens the examples and zipped projects directly.
Installed, score runs on Windows (x64 and ARM), macOS, Linux and Raspberry Pi, with the same project files and the same features, apart from those tied to an operating system or to hardware, such as Spout, Syphon or CUDA ([embedded](https://ossia.io/score-docs/in-depth/embedded.html)).

There is a library of example scores for audio, video, 3D, AI, devices and data, and each object links to its documentation ([examples](https://ossia.io/score-docs/examples.html), [quick start](https://ossia.io/score-docs/quick-start.html)).

## Through the semester

Students can start with cables and timelines and move on to JavaScript, Faust, shaders or C++ in the same project ([JavaScript](https://ossia.io/score-docs/processes/javascript.html), [shaders](https://ossia.io/score-docs/processes/shaders.html), [Faust](https://ossia.io/score-docs/processes/faust.html)).
Sound and synthesis, video and 3D, DMX lighting, sensors and Arduino, computer vision and AI are all in the same tool, so a class project can mix them.

For kits, a Raspberry Pi runs a finished project without a screen, with GPIO for electronics ([headless mode](https://ossia.io/score-docs/faq/nogui.html)).
The editor has about thirty skins, including colour-blind-safe and high-contrast ones.
