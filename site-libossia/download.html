Download libossia

libossia is available for many platforms and environments:

The current release is libossia 2.1.0, released on June 20, 2026. See the release notes, or browse all libossia releases on GitHub. Each download below is a single archive containing the builds for every supported operating system.

C++

The C++ package contains libossia as a shared library with a simple, stable C++ API (ossia-cpp98.hpp) and a CMake package, to integrate OSC, OSCQuery and MIDI support into any C++ application. It is built for Windows (x86_64), macOS (Apple Silicon) and Linux (x86_64).
For the complete native C++ API, or for other platforms (iOS, Android, WebAssembly, ARM Linux...), build libossia from source, for instance as a CMake subproject.

  • Download the C++ package (Windows, macOS, Linux)
  • Source code
  • Build instructions
  • API documentation
  • Examples
  • Doxygen reference

C

libossia provides a clean C89 header which wraps the most important functionality. It is part of libossia itself: build libossia from source to use it.

  • Source code
  • API documentation
  • Doxygen reference

Max/MSP

ossia-max is a Max package: unzip it into your Documents/Max 9/Packages folder (or the one of your Max version). It works on macOS (Intel and Apple Silicon) and Windows (x86_64).

  • Download the Max package (macOS, Windows)
  • Source code
  • API documentation

PureData

ossia-pd is a set of PureData externals. The recommended way to install it is from PureData itself, with Help → Find externals (search for "ossia"); on macOS, use this method. The archive below is for Windows (x86_64) and Linux (x86_64).

  • Download the PureData externals (Windows, Linux)
  • Source code
  • API documentation

C#, Unity

libossia provides a C# binding with a Unity integration layer, distributed as a Unity package. The archive contains one package per platform: Windows (x86_64), macOS (Intel and Apple Silicon) and Linux (x86_64). The C# scripts do not depend on Unity and can be used from any C# code base.

  • Download the Unity package (Windows, macOS, Linux)
  • Source code
  • API documentation

Qt / QML

libossia integrates with the QML markup language, to easily build performant user interfaces that can be controlled over OSC and OSCQuery. The QML module is built for macOS (Apple Silicon) and Linux (x86_64); on other platforms, build it from source.

  • Download the QML module (macOS, Linux)
  • Source code
  • API documentation

Python

pyossia lets you create and control OSC, OSCQuery and MIDI devices from Python. It can be built from the libossia sources; an older version is also available on PyPI.

  • Source code
  • pyossia on PyPI
  • API documentation

SuperCollider

ossia-sclang is a SuperCollider quark which exposes SuperCollider parameters over OSC and OSCQuery.

  • Source code and installation
  • API documentation

openFrameworks

ofxOscQuery is an openFrameworks addon to easily expose a tree of ofParameters over OSCQuery.

  • Downloads (Windows, macOS, Linux)
  • Source code and examples

Java, Kotlin, Processing

libossia provides JVM bindings, which allow it to be used from Java, Kotlin, Processing or OpenRNDR. They are not part of the current binary release: build them from the libossia sources.

  • Source code
  • API documentation

Faust

libossia provides a Faust architecture file which exposes the controls of a Faust program over OSCQuery.

  • Faust architecture file
