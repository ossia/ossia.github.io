Les nouveautés de chaque version sont décrites dans le journal des modifications (en anglais), qui donne aussi accès à d’autres téléchargements ; d’autres options d’installation sont détaillées plus bas sur cette page.


Configuration minimale

  • score nécessite un système d’exploitation et un processeur 64 bits, sur ordinateur comme sur les plateformes embarquées.
  • Sur x86_64, les versions officielles pour Windows et Linux nécessitent un processeur compatible AVX2 ; sinon, il faut utiliser un paquet de distribution, comme ceux de MSYS2 ou de l’AUR d’Arch Linux.
  • Processeur à 800 MHz, 512 Mo de RAM : score fonctionne par exemple sur un Raspberry Pi Zero 2W.
  • Pour le rendu graphique, une carte graphique compatible au moins avec OpenGL 3.2, Vulkan, Direct3D 11 ou Metal.
  • Le NDI Runtime (v5 ou plus) peut être nécessaire pour utiliser NDI.
  • Le SDK UltraLeap (Gemini ou Hyperion au moins) peut être nécessaire pour utiliser les capteurs UltraLeap.

Windows

  • Windows 10 et 11 sont pris en charge, pas les versions antérieures.
  • score et libossia utilisent Bonjour pour la découverte automatique des appareils OSCQuery : sous Windows, il faut donc installer les Services d'impression Bonjour.

macOS

macOS 12 Monterey au minimum ; les fonctionnalités d'IA nécessitent macOS 13 Ventura ou plus récent.

La dernière version pour macOS 10.15 Catalina et macOS 11 Big Sur est la 3.4.1, téléchargeable depuis la page de la version 3.4.1.
La dernière version pour macOS 10.13 High Sierra est la 3.1.8, téléchargeable depuis la page de la version 3.1.8.

Linux (ordinateur)

Pour intégrer l'AppImage au système, voir :
    https://github.com/AppImage/awesome-appimage/#desktop-integration
Attention : AppImageLauncher avant la version 3.0.0 ne prend pas en charge l'AppImage de score et plante ; voir cette discussion, et mettre à jour AppImageLauncher.

Toutes les distributions Linux depuis 2022 environ devraient fonctionner :
  • Les paquets sont compilés sur AlmaLinux 9.
  • Ubuntu 22.04 et suivantes
  • Debian Bookworm, etc.
  • Fedora 36 et suivantes
  • Le système doit avoir au moins glibc 2.34, ainsi que X11, ALSA, libGL, librt, libdbus et libEGL ; ces paquets sont présents sur toutes les distributions de bureau courantes (Debian, Ubuntu, Fedora, OpenSUSE, Arch Linux, etc.).
  • JACK ou PipeWire pour l'audio, et Avahi pour Bonjour, sont recommandés.
  • libbluez peut être nécessaire pour les Wiimotes (qui passent par Bluetooth) et pour Bluetooth LE.
  • La prise en charge de Wayland est encore expérimentale, en particulier sur les bureaux basés sur GNOME.

Ubuntu 22.04 et suivantes

Sous Ubuntu, fuse2 doit être installé, car il est nécessaire pour lancer les AppImages : 
sudo add-apt-repository universe
sudo apt install fuse2

Linux (Raspberry Pi, embarqué...)

Lire la documentation (en anglais) avant d'utiliser score sur un Raspberry Pi.
Le paquet pour Raspberry Pi a aussi été testé sur Arch Linux ARM et Asahi Linux (Mac M1).
Les versions Flatpak et Nix existent aussi en AArch64.


Installer avec un gestionnaire de paquets

  • Flatpak : flatpak install flathub io.ossia.score
  • Arch Linux (AUR) : paru -S ossia-score
  • Nix : nix-shell -p ossia-score
  • FreeBSD : pkg install ossia-score
  • MSYS2 : pacman -S mingw-w64-ucrt-x86_64-ossia-score (UCRT64), mingw-w64-clang-x86_64-ossia-score (CLANG64) ou mingw-w64-clang-aarch64-ossia-score (CLANGARM64)
  • WinGet : winget install -e --id ossia.score
  • Homebrew : brew install --cask ossia-score
