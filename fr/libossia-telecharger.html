Télécharger libossia

libossia est disponible pour de nombreux environnements et plateformes :

La version actuelle est libossia 2.1.0, sortie le 20 juin 2026. Voir les notes de version (en anglais), ou parcourir toutes les versions de libossia sur GitHub. Chaque téléchargement ci-dessous est une archive unique qui contient les builds pour tous les systèmes d'exploitation pris en charge.

C++

Le paquet C++ contient libossia sous forme de bibliothèque partagée, avec une API C++ simple et stable (ossia-cpp98.hpp) et un paquet CMake, pour intégrer la prise en charge d'OSC, d'OSCQuery et du MIDI à n'importe quelle application C++. Il est compilé pour Windows (x86_64), macOS (Apple Silicon) et Linux (x86_64).
Pour l'API C++ native complète, ou pour d'autres plateformes (iOS, Android, WebAssembly, Linux ARM...), il faut compiler libossia depuis les sources, par exemple comme sous-projet CMake.

C

libossia fournit un en-tête C89 propre qui couvre les fonctionnalités les plus importantes. Il fait partie de libossia : pour l'utiliser, il faut compiler libossia depuis les sources.

  • Code source
  • Documentation de l'API

Max/MSP

ossia-max est un package Max : il suffit de le décompresser dans le dossier Documents/Max 9/Packages (ou celui de sa version de Max). Il fonctionne sous macOS (Intel et Apple Silicon) et Windows (x86_64).

  • Télécharger le package Max (macOS, Windows)
  • Code source
  • Documentation de l'API

PureData

ossia-pd est un ensemble d'externals PureData. La méthode d'installation recommandée passe par PureData lui-même, avec Help → Find externals (en cherchant "ossia") ; sous macOS, c'est cette méthode qu'il faut utiliser. L'archive ci-dessous est pour Windows (x86_64) et Linux (x86_64).

  • Télécharger les externals PureData (Windows, Linux)
  • Code source
  • Documentation de l'API

C#, Unity

libossia fournit un binding C# avec une couche d'intégration pour Unity, distribué sous forme de package Unity. L'archive contient un package par plateforme : Windows (x86_64), macOS (Intel et Apple Silicon) et Linux (x86_64). Les scripts C# ne dépendent pas de Unity et peuvent être utilisés depuis n'importe quel code C#.

  • Télécharger le package Unity (Windows, macOS, Linux)
  • Code source
  • Documentation de l'API

Qt / QML

libossia s'intègre au langage de balisage QML, pour construire facilement des interfaces utilisateur performantes contrôlables par OSC et OSCQuery. Le module QML est compilé pour macOS (Apple Silicon) et Linux (x86_64) ; sur les autres plateformes, il faut le compiler depuis les sources.

  • Télécharger le module QML (macOS, Linux)
  • Code source
  • Documentation de l'API

Python

pyossia permet de créer et de contrôler des appareils OSC, OSCQuery et MIDI depuis Python. Il peut être compilé depuis les sources de libossia ; une version plus ancienne est aussi disponible sur PyPI.

  • Code source
  • pyossia sur PyPI
  • Documentation de l'API

SuperCollider

ossia-sclang est un quark SuperCollider qui expose des paramètres SuperCollider par OSC et OSCQuery.

  • Code source et installation
  • Documentation de l'API

openFrameworks

ofxOscQuery est un addon openFrameworks pour exposer facilement un arbre d'ofParameters par OSCQuery.

  • Téléchargements (Windows, macOS, Linux)

Java, Kotlin, Processing

libossia fournit des bindings pour la JVM, qui permettent de l'utiliser depuis Java, Kotlin, Processing ou OpenRNDR. Ils ne font pas partie de la version binaire actuelle : il faut les compiler depuis les sources de libossia.

  • Code source
  • Documentation de l'API

Faust

libossia fournit un fichier d'architecture Faust qui expose les contrôles d'un programme Faust par OSCQuery.
